# SAFIRA
Sistema inteligente para a detecção e avaliação dos estímulos do ambiente, voltado para o bem-estar de pessoas com TEA (Transtorno do Espectro Autista)

## Como executar o projeto

Após baixar o repositório e acessá-lo via terminal, execute os seguintes comandos:

```bash
cd safira
```
```bash
npm init
```
```bash
npx expo start
```

Com isso, você deve ser redirecionado para a tela de login, onde poderá criar uma conta.
